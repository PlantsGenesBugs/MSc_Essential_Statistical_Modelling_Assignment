## Final assignment for University of Birmingham, MSc module on Statistical Modelling.

This assignment consisted of two parts:

### 1. Snakes and Ladders  
You produce a simulation of a game of snakes and ladders (https://en.wikipedia.org/wiki/Snakes_and_Ladders) based on the board configuration shown below (image withheld for sake of academic integrity).  

Q1: Comment code.   
Q2: Extend code to incorporate effect of snakes and ladders.  
Q3: Simulate a single player game and calculate number of turns to reach the 100th square. Repeat this 1000 times and plot the subsequent distribution. 

### 2. Data Analysis
Analyse mock data representing a gene expression matrix obtained from a sample of patients.

Q4: Comment code.  
Q5: Identify a problematic sample (and remove it).    
Q6: Perform a regression-based differential expression analysis (comparing tumour and normal samples) using the glm() function from the MASS package.
